### 新暴露的缺陷（P0.5）

**根因修正：`attrib` 算子把领属关系误当定语从句展开。**

初判为"跨句串句"，经源码复核后**推翻该判断**。实际根因在 `rewriter/operators/attrib.py:67`：

```python
else:
    clause = '它是' + ''.join(m) + '的'
```

S4 规则把「真理的客观性」解析为 `[M]的[N]`（M=「真理」，N=「客观性」），当定语 M 不含动词时走 else 分支，无条件拼出「它是{M}的」，得到「它是真理的」。

两个不同句子出现相同尾巴，是因为它们都以「真理的X」开头，各自独立命中同一规则，**并非跨句数据污染**。

```

```
原句A：真理的客观性决定了真理的一元性。
  新：客观性决定了真理的一元性，它是真理的。
原句B：真理的客观性表明。要想发现真理……只能采取。
  新：客观性表明，要想发现真理……取得成功。只能采取，它是真理的。   ← "它是真理的"来自原句A
```

该候选 `fidelity=0.8706`，高于 0.65 门槛，未被拦截。说明保义度指标对"跨句污染"不敏感——因为它只比对原句结构，不检查候选是否混入了原文其它句的内容。

**这是比原病句更严重的问题**：病句是"读着别扭"，串句是"内容错乱"，在论文里属于硬伤。

## 四、结论

1. **P0 目标达成一半**：三个已知病句模式被消除，保义度从 82% 提升到 85%。
2. **代价是覆盖率下降**：从 31% 到 25%，最长重合退回 39 字。原先靠低门槛硬拆换来的"效果"，本质是拿语义完整性换的，收掉后真实能力暴露出来。
3. **规则算子已到天花板**：6 个算子在真实学术长句上的覆盖率上限就在 25–31%。继续调规则只能抠 1–2 个百分点，无法质变。
4. **必须先修跨句串句**，否则任何扩大覆盖率的尝试都会放大错误。
